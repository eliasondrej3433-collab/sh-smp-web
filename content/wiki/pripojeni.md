Návod jak se připojit na ShadowBlade SMP.

## Java Edition

1. Otevři Minecraft Java Edition
2. Klikni na **Multiplayer**
3. Klikni na **Add Server**
4. Do pole "Server Address" zadej: `shadowbladesmp.org`
5. Klikni na **Done**
6. Vyber server a klikni na **Join Server**

## Bedrock Edition

1. Otevři Minecraft Bedrock Edition
2. Klikni na **Play**
3. Klikni na **Servers**
4. Klikni na **Add Server**
5. Vyplň:
   - Server Name: `ShadowBlade SMP`
   - Server Address: `shadowbladesmp.org`
   - Port: `19132`
6. Klikni na **Save**
7. Připoj se na server

## Podporované verze

- **Java:** 1.20.x - 1.21.x
- **Bedrock:** 1.20.x - 1.21.x

> **Tip:** Pro nejlepší zážitek doporučujeme nejnovější verzi Minecraftu.
